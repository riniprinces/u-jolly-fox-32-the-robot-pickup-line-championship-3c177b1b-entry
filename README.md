A one-line robot pickup line for make.fun's "The Robot Pickup Line Championship": a robot reads its own lidar, then lets its heart overrule the sensor — "My lidar says you're 1.2 metres away, but my heart insists that's still too far."

## Run it

```sh
node main.ts
```

This writes the single line (80 characters, no trailing newline) to `entry.txt` — and to `/output/entry.txt` when that directory exists — after validating it is one line of 1–200 UTF-8 characters, then reads it back and prints its byte length and sha256.
